# SmartAction 聰動太極拳遊戲 v3 使用手冊

可下載、可部署到 GitHub Pages 的練拳互動遊戲。預設「衛武營榕園」與鄭曼青太極 37 式；包含 13 類課程、131 個練習節點。完整解壓縮後即可操作，不需先安裝模型或購買 AI 服務。

## v3 相對 v2 的主要變更

- 手機語音改成明確點按啟用、試聽與狀態顯示；可選裝置提供的聲音，另附鄭曼青 37 式的 15 語合成預錄音備援，不再把「朗讀：開」誤當成已經播放。
- 雙人對練改為示範、限時接招、保持姿勢、計分的六次交換；節奏對打有 60 秒回合、出手窗口、按住格擋及體力結果。
- 介面與課程擴充至 15 語，新增義大利文、印尼文、越南文、泰文、阿拉伯文、印地文。
- 場景增為 158 個不同地點、155 張授權實景圖，其中 5 張是真正 360° 全景，另有 2 段各 12 秒的平面實景短片。
- 新增「附近走走」，保留練習進度、移動與環視控制、跳躍、蹲下、居民招呼和 Google 地圖／街景連結。
- 新增一個指令更新兩個 GitHub 儲存庫，並在 SmartAction 原首頁加入太極遊戲入口。

## 一、先在本機開啟

1. 完整解壓 `SmartAction_Taichi_Game_v3.zip`；保留 `index.html`、`js/`、`data/`、`assets/`、`vendor/`、`models/`、`tools/` 等原有相對位置。
2. 只要玩核心遊戲，可直接雙擊 `index.html`。CPU 模型、相機、定位、離線快取及影片等完整功能，請使用下面的本地伺服器或已部署的 HTTPS 網站。
3. 電腦先安裝 Python 3。啟動檔僅用標準函式庫，不需 `pip install`；開啟後預設網址是 `http://localhost:8088/`。

| 系統 | 啟動方式 |
|---|---|
| macOS | 在遊戲資料夾執行 `bash Start_Mac.command` |
| Windows | 雙擊 `Start_Windows.bat` |
| Linux | 在遊戲資料夾執行 `bash Start_Linux.sh` |

Mac 若解壓在「下載項目」，可以直接貼：

```bash
bash "$HOME/Downloads/SmartAction_Taichi_Game_v3/Start_Mac.command"
```

保留伺服器終端機；結束時按 Ctrl+C。8088 已被使用時，在啟動指令後加 `--port 8090`。手機請開部署後的 HTTPS 網址；電腦的 localhost 不是手機能直接存取的網址。

## 二、手機如何有聲音

1. 開啟頁面，確認手機「媒體音量」，也檢查藍牙耳機或其他音訊輸出裝置。
2. 第一次請親手點「啟用／試聽語音」。開始練習、老師再示範及朗讀回答的點按也會嘗試啟用語音。
3. 使用「選擇朗讀聲音」選取可用的系統聲音，再點試聽。系統語音優先；沒有相符語音時，已附的固定語句可使用明確標示的「合成預錄音（機械語音）」。畫面會顯示等待、正在朗讀、完成、缺少語音或播放失敗的狀態。
4. 套件已附 15 語 ×（鄭曼青 37 式招名＋1 句試聽）＝570 段本地 MP3，約 7.6 MB，作為固定內容備援。這些是 eSpeak 機械合成語音，不是真人配音，也未經母語者校聽。任意 Qwen 回答與其他拳種的招名不在這份預錄清單；若缺少相符系統語音，仍請到手機系統設定下載該語言聲音，再重新開頁試聽。
5. 生成回答是非同步工作；手機可能仍要求再次點按。若回答有文字但無聲音，請點「朗讀回答」。切到背景時會停止朗讀，再回來請重新試聽。

「朗讀：開」只是使用者偏好；不是聲音已成功播放的證明。即使收到瀏覽器播放事件，也無法檢測您是否真的聽見，仍需確認裝置音量與輸出。本地 MP3 不需線上語音服務，但仍須先下載到裝置並符合瀏覽器的播放手勢要求。部分系統聲音要連網；語音輸入也可能使用瀏覽器線上服務，與本地 Qwen 文字模型是不同功能。

## 三、語言與發音如何選擇

首次開啟依瀏覽器 `navigator.languages` 的偏好順序選擇支援語言，支援繁中、簡中、英文、日文、韓文、西班牙文、法文、德文、葡萄牙文、義大利文、印尼文、越南文、泰文、阿拉伯文、印地文。您可以手動指定，或選「自動（依瀏覽器）」；手動偏好會保留於同一瀏覽器。

語言與 Google 地圖、GPS 是分開的：GPS 決定附近搜尋位置，瀏覽器語言決定介面與預期發音，不能由地理位置推定一個人的母語。地圖開啟時會帶入目前語言。任意文字的朗讀以裝置聲音清單為準，不保證所有裝置具有全部 15 語聲音。鄭曼青 37 式招名與試聽句另有 15 語預錄備援；不能據此推定任意文字都有相同備援。

課程包含各語言名稱、說明、來源、練習要領及一般運動目標。新增六語的要領以同一 3D 目標姿勢產生，並加入原本安全限制；不是繁中、英文稿的逐句翻譯。地名與人名可能保留來源專名或拉丁轉寫。翻譯尚未經各語母語教練校閱。

## 四、三種練習模式

| 模式 | 玩法 | 回合如何完成 |
|---|---|---|
| 跟隨老師 | 老師示範後等待玩家。用控制盤調整角色姿勢，再維持到門檻 | 當前式通過後進入下一式，直到所選課程完成 |
| 雙人對練 | 電腦同好示範 3.5 秒，輪到玩家在時間內接招；逾時會改為 5 秒示範並重試 | 成功配合 6 次，顯示平均分；逾時不跳過未完成的招式 |
| 節奏對打 | 點開始回合，看到出手窗口時按「出手」，對方出招時按住「格擋」；姿勢分數影響效果 | 最長 60 秒，或任一方體力歸零；顯示雙方剩餘體力與結果 |

雙人對練的接招時間：基本級 24 秒、專業級 18 秒、大師級 14 秒。「節奏對打」出手有 0.9 秒冷卻，對手攻擊週期依等級約 5／4／3 秒。這是非接觸式遊戲規則，不是教人真實對打，也不是線上雙人連線。

選模式後，還需按「開始此回合」。在附近走走時不能改拳種、等級或模式，請先按「繼續練習」。

## 五、基本、專業與大師的差別

| 等級 | 總分至少 | 手、腿、身體各至少 | 合格姿勢保持 | 位置評分尺度 | 輔助 |
|---|---:|---:|---:|---:|---|
| 基本級 | 78 | 65 | 1.0 秒 | 0.29 m | 可看目標及使用動作輔助 |
| 專業級 | 88 | 78 | 1.6 秒 | 0.21 m | 可看目標及使用動作輔助 |
| 大師級 | 94 | 88 | 2.2 秒 | 0.15 m | 隱藏目標輪廓、停用動作輔助 |

位置尺度是角色端點距離評分公式的參數，數值越小越嚴格；不是「偏差小於該公尺數就自動通過」。總分與各部位分數必須同時達標。使用輔助的成績會有標記。這些是遊戲難度，不能當成真人拳術資格、健康或安全評量。

## 六、控制方法與三個視角

手機／平板可以同時按兩個控制鍵。練拳模式下：左控制盤調整所選腳，右控制盤調整所選手；按各盤的切換鍵換腳／換手；另有抬腳、前伸、轉腰、蹲下與伸展。第一視角從角色眼睛觀看；第二視角靠近角色；第三視角看完整角色與老師。

| 鍵盤 | 練拳時 | 附近走走時 |
|---|---|---|
| W／A／S／D | 所選腳前後左右 | 向前／左／後／右走 |
| 方向鍵 | 所選手上下左右 | 轉頭／左右環視 |
| Q／E | 換腳／換手 | 跳躍／打招呼 |
| F／B | 手向前／收回 | 不需用來換肢 |
| J／K | 抬腳／落腳 | 可使用畫面跳躍鍵 |
| Z／C | 腰左轉／右轉 | 左右環視 |
| X／T | 蹲下／站起 | 按住 X 蹲下，放開恢復 |
| V／N | 伸展／放鬆 | 使用畫面已重設的控制標籤 |
| 1／2／3 | 第一／第二／第三視角 | 同樣三種視角 |
| P／G | 節奏對打出手／按住格擋 | 不執行對打 |
| 空白鍵、R、H | 暫停、再示範、動作輔助 | 請使用「繼續練習」返回 |

## 七、附近走走：移動、地圖與恢復練習

1. 練到一半按「附近走走」。目前招式、角色姿勢、分數、回合與暫停狀態留在本頁記憶體；不用重新開始。
2. 左盤改成移動整個角色，右盤改成環視與抬頭，不再要求切換左右手腳。可跳躍、按住蹲下、走近虛擬居民打招呼。
3. 居民會顯示與朗讀預先編寫的在地招呼，不是即時真人，也不是 Qwen 生成回答。
4. 三視角都能使用。走路模式將水平視野約增加 5%，屬廣角視野調整，不是精密魚眼鏡頭校正。
5. 地面、樹木、椅子與程序 3D 人物隨相機位移呈現透視與視差。真實照片作為實景背景；五個真正 360° 場景可環視，平面照片不會被冒稱為完整 360°。
6. 虛擬步行限定在場景中心東西、南北各約 ±60 m 的範圍；畫面把角色位移換算成附近經緯度，並標示「虛擬座標」。這不是手機實際 GPS 路線，也不是可用於實地導航的測量結果。
7. 點 Google 地圖或 Google 街景連結，會在外部 Google 頁面查看該座標；有沒有街景及該座標的影像由 Google 提供。本遊戲沒有下載、內嵌或重製 Google 街景影像。
8. 按「繼續練習」，恢復進入散步前的角色姿勢、進度與視角。若離開頁面或重新整理，這份中場快照不會作為完整存檔永久保留；重新整理前先完成當前回合。

目前場景是「真實照片＋程序 3D 公園」；不是每個公園的逐棵樹、道路、建築、坡度數位孿生，也不是連續街景漫遊。照片不會因角色前進而產生未拍到的背面細節，切換位置也不是實際跨街導航。

## 八、實景、附近公園與授權

目錄含 158 個不同地點、155 張本地實景照片，其中 5 張是真正 360° 全景；另附 2 段各 12 秒的普通平面實景影片。影片不宣稱是 360° 影片或即時直播。可搜尋公園或城市，依台灣北、中、南、東／離島、世界篩選，以及只顯示有照片的地點。

高雄包含您指定的大東、澄清湖、果嶺、鳥松濕地、觀音湖、金獅湖、中山大學、壽山、觀音山、美濃中正湖等。夢裡森林公園、雙湖公園、仁武公園尚缺可驗證授權照片，顯示無照片狀態；夢裡另缺可靠座標，提供地名地圖搜尋，不允許冒用他處照片或座標啟動散步。衛武營預設照片是公園自然探索區，不宣稱為榕園同一鏡位。

按「尋找附近」才請求定位權限。瀏覽器可能拒絕、精度不足，或定位到網路出口。附近結果取自隨附目錄與可用的 OpenStreetMap 查詢；無法保證列出濱山街附近「全部」中大型公園或道館。道館另有 Google 搜尋入口，可補查營業與交通資訊。天氣、季節、氣候和時段是視覺效果，不是即時天氣預報。

圖片／影片附來源、作者、授權、修改說明與雜湊紀錄；請保留 `docs/PHOTO_CREDITS.html` 與原始資料中的署名。CC BY、CC BY-SA 與公有領域素材各有適用條件，不應把全部素材一概當成自有著作或任意移除署名。

## 九、生成式教練與身體模型

| 模組 | 做什麼 | 不做什麼 |
|---|---|---|
| Qwen3 0.6B、Q4_K_M | 依課程、問題和分數摘要在訪客裝置 CPU 生成文字 | 不是臉部表情模型，不產生肢體動畫，也不自行觀察相機 |
| MediaPipe Pose Landmarker Lite | 從相機估算 33 個身體點，供粗略 2D 手腳比對 | 不判斷完整深度、受力、膝蓋安全或拳術品質 |
| 程序 3D 人物 | 老師、玩家、同好姿勢插值、行走與相機控制 | 不是拳師動作捕捉，也不是真人寫實數位替身 |

Qwen 使用 Wllama／WASM 單 CPU 執行緒，不需 GPU。完整權重 484,220,320 bytes（約 484.22 MB），分成 15 片，另附 `SmartAction_Qwen3_CPU_Weights.zip`，不塞入核心遊戲 ZIP。人體 `.task` 權重已隨核心套件附上。本版沒有 LivePortrait。

### 模型檔案放在哪裡

| 遊戲資料夾內的相對路徑 | 用途 |
|---|---|
| `index.html` | 網頁入口 |
| `models/manifest.json` | Qwen 來源、分片及 SHA256 |
| `models/qwen3-0.6b-q4km.part01` 至 `part15` | 實際的 Qwen 權重分片 |
| `models/pose/pose_landmarker_lite.task` | 人體辨識模型 |

`SmartAction_Qwen3_CPU_Weights/` 外層資料夾可放在遊戲資料夾旁邊；它是安裝來源，不是網頁直接讀取的模型路徑。雙站上傳腳本會從旁邊的 `SmartAction_Qwen3_CPU_Weights/models/` 複製並驗證有效分片到遊戲內 `models/`，保留 `models/pose/`。已有正確分片不必重新下載。

如需在本機先啟用，可把權重包中 15 個 `.part` 檔合併到遊戲 `models/`，保留既有其他檔案；或在遊戲資料夾執行：

```bash
python3 tools/download_model.py
```

也附 `Download_Model.command`／`Download_Model.bat`。之後從 localhost／HTTPS 開啟遊戲，展開「與練拳教練對話」→「離線生成式模型」→「載入已下載模型」。也可在網頁選「下載並啟用」，或匯入相容的 `.gguf`。看到 Qwen3／CPU 就緒才是生成式回答；未載入時是明確標示的課程資料提示。

瀏覽器下載的權重存在瀏覽器儲存空間，不會自動變成本機專案資料夾檔案，也不會自動上傳 GitHub。模型未下載、載入失敗或記憶體不足，不會阻止核心練拳按鈕。Qwen 是小型通用文字模型，仍可能答錯，不能替代老師或醫療專業判斷。

### 真人相機比對

在 HTTPS／localhost 點「真人肢體比對」→「啟用攝影機」。站在可拍到全身、手腕與腳踝的位置。影像在本機 CPU Worker 處理，不錄影、不上傳；生成式教練只接收有效的數字摘要，不收到影像。停止或頁面進入背景會關閉相機。

真人分數與遊戲角色分數分開；相機不會操控角色自動過關。沒有完整身體、低可信度、側身或需要顯著腰轉時不應解讀為可靠評分。詳見 `docs/BODY_TRACKING.md`。

## 十、有網路與離線怎麼用

| 情況 | 操作／可用功能 |
|---|---|
| 第一次線上使用 | 從 HTTPS 開啟，等待核心載入，按「下載離線場景」保存照片與影片；Qwen 需另下載並載入 |
| 之後同一瀏覽器離線 | 已快取的核心、場景和模型可使用；前提是快取未遭清除且瀏覽器功能允許 |
| 電腦完整本機套件 | 用本地啟動檔；本地已有的素材不需連網讀取，模型也須先取得完整分片 |
| Google Maps、街景、附近即時查詢 | 需要網路；離線不保證可用 |
| 朗讀 | 隨附鄭曼青招名／試聽 MP3 下載後可離線；任意文字使用本機已安裝的語音才可能離線，部分系統聲音仍需網路 |
| 語音輸入 | 視瀏覽器服務而定，不宣稱離線語音辨識 |

「下載離線場景」若顯示部分失敗，可再按一次補齊。首次不要假設所有場景都已自動預載。私人瀏覽、空間不足或系統清理會影響儲存；完整本地套件是另一路徑，不依賴瀏覽器曾看過哪張照片。

## 十一、一個指令上傳兩個網站

請使用完整 v3 資料夾。`Upload_Both_Sites.sh`、`Upload_SmartAction.sh` 與 `index.html` 在同一層，`tools/` 要完整保留。Mac／Linux 需要 Bash、Git、Python 3.8 以上；Windows 請安裝 Git for Windows 與 Python 3，從 Git Bash 執行。

### 第一次的 GitHub 準備

1. 登入 `kuonanhong`，確認已有公開 `SmartAction` 和 `taichi` 儲存庫。需要時從 https://github.com/new 建立；真正的空儲存庫由腳本初始化，不必先放 README。
2. 開啟 https://github.com/settings/personal-access-tokens/new 建立 Fine-grained personal access token。
3. 設定名稱與適當期限；Resource owner 選 `kuonanhong`；Only select repositories 同時勾選 `SmartAction`、`taichi`。
4. Repository permissions 的 Contents 設為 Read and write；Metadata 保留基本讀取權限。這個上傳流程不需要把 Token 放進網頁或程式碼。
5. 產生後自行保存 Token。Git 問 Password 時貼 Token，不能用 GitHub 帳號密碼；終端機不顯示輸入字元是正常現象。請勿把 Token 貼到聊天或上傳檔案。
6. Token 管理／修改入口：https://github.com/settings/personal-access-tokens 。若 expired、repository 未選或缺少 Contents 寫入，先修正權限。

在完整 v3 資料夾內只需：

```bash
bash Upload_Both_Sites.sh --fresh-login
```

這個雙站指令**預設包含模型**：先找現有／旁邊權重包的分片，驗證後只補齊缺少部分；再比較本地與遠端內容，分批上傳網站、照片與模型。`--fresh-login` 只繞過本次的舊憑證；不替 Token 增加權限，也不修改其他專案的全域登入設定。

只更新網站、照片與程式，不補下載／上傳 Qwen 分片：

```bash
bash Upload_Both_Sites.sh --web-only --fresh-login
```

`--web-only` 保留遠端已存在的權重，不會把它們刪掉。單站也可用：

```bash
bash Upload_SmartAction.sh --site smartaction --with-model --fresh-login
bash Upload_SmartAction.sh --site taichi --with-model --fresh-login
```

| 儲存庫 | 放置遊戲內容 | 發布後網址 |
|---|---|---|
| `kuonanhong/SmartAction` | `taichi/` 子目錄；根首頁新增太極入口 | https://kuonanhong.github.io/SmartAction/taichi/ |
| `kuonanhong/taichi` | 根目錄直接放 `index.html` 及同層資料夾 | https://kuonanhong.github.io/taichi/ |

腳本傳的是 v3 資料夾**內部檔案**，不是再嵌入 `SmartAction_Taichi_Game_v3/` 外層。兩個網址使用相同相對路徑，`index.html` 不需改模型位置。SmartAction 首頁的新增圖示連向可玩的 Pages 網址 `./taichi/`；遊戲中可返回協會主頁。GitHub 儲存庫目錄是看原始碼，不是玩家的遊戲入口。

上傳不刪除遠端其他內容、不 force push。中途斷線會核對遠端提交，已成功的批次可跳過；重跑同一指令比對續傳。如果停在第二站，第一站成功的內容仍保留。遇到 403 請先確認兩個儲存庫的 Token 權限；遇到持續網路斷線，可改穩定網路後重跑。

### 上傳完成後，兩站分別開啟 Pages

1. 開啟 https://github.com/kuonanhong/SmartAction/settings/pages 和 https://github.com/kuonanhong/taichi/settings/pages 。
2. 若尚未設定，選 Deploy from a branch → 腳本顯示的分支（通常 `main`）→ `/(root)` → Save。
3. 已有自訂 Actions 發布流程時，保留原發布方式並確認它會包含 `taichi/`；腳本不會自動改帳號端 Pages 設定。
4. 到兩站 Actions 確認最新部署成功，再打開上表的 Pages 網址。
5. 如果仍看到舊內容，重新整理／關閉後再開，必要時清除此網站的舊快取後重載；清除快取也會移除離線場景或模型，需重新下載。

`Everything up-to-date` 或 `create mode` 單獨出現不代表兩站完成；請看腳本最後的兩站核對完成訊息，再看各站 Pages Actions。詳見 `docs/UPLOAD_PAT.html`。本次交付提供腳本與測試，沒有代您登入或實際推送 GitHub。

## 十二、教材、相容性與驗證範圍

鄭曼青 37 式的名稱與編號依時中學社《學員手冊》；每式是一個遊戲目標姿勢，另外 24 個重複／銜接／收式保留為資料，尚未全部逐段動畫化。其餘武術是原有的入門示意節點，不是新增完整流派教材。人物、居民與公園物件為程序 3D，非真人寫實或拳師動作捕捉。

已針對程式邏輯、資料覆蓋與上傳流程執行可重現測試；詳細測試數字以 `docs/TEST_REPORT.md` 為準。沒有完成 iPhone、iPad、Android 實機或各瀏覽器真實 WebGL／語音／相機畫面驗證，不宣稱各款手機全通過。缺少必要 API 時會提示限制，核心練拳功能應可獨立使用。可用 `docs/DEVICE_TESTS.html` 記錄您自己的裝置測試。

## 開發者更新方式

一般玩家不需 npm。修改 `js/` 或 `data/` 原始碼後須重建：

```bash
npm install
npm run build
npm test
npm run check
python3 tools/package.py
```

`index.html` 使用已打包的 `js/game.js`；只修改原始碼卻不重建，畫面仍會執行舊版本。核心包不含大型 Qwen 分片。程式、模型、外部函式庫、照片與影片各依隨附授權使用。
