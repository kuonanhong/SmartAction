# Natural fixed-line voice banks · SmartAction v4

本套件新增 8 種神經語音聲線：普通話男聲／女聲各 2 種，美式英文男聲／女聲各 2 種，共 304 個離線 MP3。每種聲線包含本遊戲鄭曼青 37 式名稱與 1 段試聽。繁體／簡體中文介面共用普通話音檔；不是臺灣腔模型，也不是真人錄音。這些聲線支援固定台詞，任意教練回答仍需裝置的文字轉語音服務。全部模型權重只用於離線製作，不放進網站；使用者播放 MP3 不需 API key。

These are AI-generated speech clips, not human recordings and not recordings of any instructor or user. Kokoro voice identifiers are upstream model identifiers. The four Chinese banks speak Mandarin Chinese (`zh-CN`); selecting the Traditional Chinese interface does not turn them into Taiwanese-accent models.

## What is included

Eight independent voice styles, each with 37 Cheng Man-ch’ing movement announcements and one test sentence: **304 MP3 files**. Traditional and Simplified Chinese labels share the same Mandarin recording; they are not counted twice. For very short movement names, the recording says “下一式，…” or “Next movement, …” to provide speaking context. Names, exact spoken scripts, phonemes, SHA-256, bytes, decoded duration, RMS and peak for every clip are in `data/natural-voices-v4.json`.

These MP3 banks cover the listed fixed announcements. They are not a browser TTS engine for arbitrary questions. Other curricula, new dialogue, or other languages use a suitable installed browser/system voice or another explicitly labelled fallback. Browsers may require a click or tap before audio playback. Neural speech can mispronounce rare terms; it is not a guarantee of native-speaker accuracy. The project applies dictionary overrides `peng2` for the tai chi term 掤 and `ao4` for 拗步; the latter follows the form-name pronunciation given by <https://www.singongtaichi.com/cmc37form.html>.

## Reproduce on a CPU

Requirements: Python 3.12, Node.js, FFmpeg with libmp3lame, and a platform supported by the listed Python packages. Generation was verified on Linux CPU; the website only needs the generated MP3 files and does not require Python or these native packages. Create the environment outside the website directory. From the project directory:

```bash
python3 -m venv "$HOME/.venvs/smartaction-kokoro"
"$HOME/.venvs/smartaction-kokoro/bin/pip" install \
  'kokoro-onnx==0.4.9' 'misaki[zh]==0.9.4' \
  'onnxruntime==1.31.0' 'numpy==2.5.4' 'soundfile==0.14.0' \
  'pypinyin==0.55.0' 'espeakng-loader==0.2.4'
"$HOME/.venvs/smartaction-kokoro/bin/python" tools/generate_natural_speech.py --workers 2 --threads 2
```

The first generation downloads about 354 MB to `$HOME/.cache/smartaction-kokoro-v1`, outside the website. Downloads are checked against pinned SHA-256 values. Each generation worker uses `CPUExecutionProvider`, with no CUDA/GPU requirement. The script sets `ORT_DISABLE_TELEMETRY=1` before ONNX Runtime is imported and also calls `disable_telemetry_events()`. The first option is the official process-lifetime opt-out, which also prevents the initialization uploader; see <https://github.com/microsoft/onnxruntime/blob/main/docs/Privacy.md>. The inference stage reads local model files only. To reduce peak RAM, use `--workers 1 --threads 2`. Existing clips are decoded and verified rather than regenerated; to intentionally regenerate a bank, move that bank’s output folder elsewhere first. Different ONNX Runtime, FFmpeg or platform versions may produce different bytes even with equivalent sound. Source-file checksums, spoken scripts and settings make the procedure reproducible; bitwise output identity across all operating systems is not promised.

To verify only the shipped audio hashes, with no model download or extra Python package:

```bash
python3 tools/generate_natural_speech.py --verify-only
```

Audio: mono, 24 kHz MP3, 64 kbit/s. Generation: float32 Kokoro v1.0 model, speaking speed 0.92 for Mandarin and 0.94 for English. The script reads the model’s speed tensor type explicitly, avoiding an int32/float mismatch in older wrapper code. Every MP3 is decoded by FFmpeg and checked for finite, non-silent samples before the final manifest is written.

## Verification scope

Automated checks establish that all files decode, match their hashes, contain non-silent finite samples, and that each language includes two male and two female model styles. They do not establish subjective naturalness, perfect pronunciation, or playback on every physical phone. A natural voice in one operating system cannot be installed into another by a website; the included MP3 banks provide consistent fixed-line sound across compatible browsers while the system-voice list remains device-dependent.
