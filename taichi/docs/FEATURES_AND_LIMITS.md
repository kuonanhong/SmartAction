# SmartAction v4 功能與實際範圍

本頁區分已寫入程式的功能與仍須實機驗證／資料建置的範圍。使用步驟見 [HTML 手冊](guide.html)，測試證據見 [測試報告](TEST_REPORT.md)。v3 的課程、場景與遊戲模式保留。

| 項目 | 本版實作 | 明確限制 |
|---|---|---|
| 核心入口 | classic `js/game.js`，完整解壓後可從 `index.html` 操作 | CPU、相機、GPS、媒體和快取完整功能需 HTTPS／localhost |
| 課程 | 鄭曼青 37 主式；總計 13 類、131 節 | 每節一個程序目標姿勢；24 銜接資料未全動畫化；非拳師動捕或認證教材 |
| 跟隨老師 | 示範後等待玩家，各部位與總分達標且保持才通過 | 計分是遊戲角色端點距離，不是真人拳術判定 |
| 雙人對練 | 6 次電腦示範／玩家接招；24／18／14 秒窗口；逾時重試 | 電腦配對，不是兩位真人網路連線；不是完整攻防教學 |
| 節奏對打 | 最長 60 秒，出手／格擋提示、冷卻、體力和勝負 | 非接觸遊戲，不教真人實戰安全 |
| 三種等級 | 78／88／94 總分；部位至少 65／78／88；保持 1／1.6／2.2 秒；位置尺度 0.29／0.21／0.15 m | 尺度是高斯距離分數參數，不是允許誤差半徑；大師隱藏目標並禁輔助 |
| v4 版面 | 場景與底部操作盤相鄰；設定可收合；安全區、直橫向、可視視窗與縮放調整；主要觸控目標至少44 px的設計 | 真實 Safari／Android 工具列、軟鍵盤與旋轉仍需實機測；程序人物不因版面修正變成寫實數位人 |
| 語音啟用與狀態 | 點開始／啟用時同步解鎖；來源、聲型、語速記憶、重播、音檔試聽；處理閒置取消、過期回呼與重複請求；固定句的系統語音錯誤／停滯可切本地備援 | blocked 截圖不足以判定 OS 根因；播放事件不能證明實際聽見；受手勢、裝置音量與輸出限制 |
| 自然固定語音 | Kokoro-82M 製作 8 組×38句＝304 MP3；普通話2男2女、英文2男2女 | 合成，不是真人；普通話不保證台灣腔。僅固定37招名與試聽句，沒有搭載約340 MB即時語音權重 |
| 18語機械備援 | eSpeak 製作18語×38句＝684本地MP3 | 較機械，未逐語經母語教練校聽；不是任意文字的通用錄音庫 |
| 任意文字朗讀 | Qwen新回答與其他動態句使用系統TTS；固定錄音無對應時回到系統聲音 | 系統API沒有可靠gender欄位，未知聲音不猜男／女；語言可用性與離線能力依裝置 |
| 18語 | 介面與全部課程字串，新增俄文／土耳其文／荷蘭文；自動瀏覽器偏好、手動覆寫、阿拉伯文方向支援 | 地理位置不決定母語；專名可用轉寫；部分要領依姿勢生成，非逐字譯本；未母語教練審校 |
| 158地點 | 搜尋、地區篩選、照片篩選、GPS／目錄／可用OSM附近結果 | 並非附近全部公園／道館目錄；資料與定位會不完整 |
| 本地實景素材 | 155張授權照片，其中5真360°；2段各12秒平面影片 | 其餘照片非360°；影片非環景影片、非直播；3指定公園缺圖並明示 |
| 附近走走 | 儲存／恢復本頁進度、方向盤重設、跳／蹲、招呼、3視角、水平視野約+5% | 不是整份長期存檔；重整會失去中場快照；人物與居民是程序3D |
| 移動與實景 | 3D地面／物件視差，照片背景；±60m虛擬範圍、角色座標換算 | 不是公園精準3D重建、連續街景或真實GPS軌跡；平面照片無背面視差 |
| Google地圖／街景 | 依角色虛擬座標開啟外部Google頁面 | 不下載重製街景；Google決定影像是否存在；不是現場路線導航 |
| 居民回應 | 靠近後顯示／朗讀預寫問候 | 不是在地真人、不是生成式人物對話；動態朗讀仍依系統聲音 |
| Qwen3 CPU | 本地Wllama／WASM文字生成、模型進度和驗證；沿用15分片共484,220,320 bytes | 非人臉／動作／TTS模型；小模型會答錯；手機記憶體與CPU速度未實測 |
| 人體辨識 | MediaPipe Lite真實權重、CPU Worker、33點、粗略正面2D比對 | 非深度、腰轉、受力或關節安全評分；不自動控制角色過關 |
| 離線 | 核心服務工作程序、使用者主動下載場景與語音、模型獨立儲存 | 首次須先下載；瀏覽器會清理儲存；地圖／即時附近／部分系統語音需網路 |
| 雙站發布 | 完整v4套件內執行一個bash；網站96MiB/批、模型兩片64MiB/批；首頁增加入口、遊戲可返回 | 需Git／Python／兩庫PAT權限；Pages另設定且需等待建置；此次未代帳號推送 |
| 驗證 | 邏輯、資料覆蓋、音訊檔案與上傳情境可重現檢查，以TEST_REPORT為準 | 未完成實體iPhone／iPad／Android及真實瀏覽器WebGL、聲音、相機全流程測試；不宣稱所有裝置全通過 |

自然語音來源與檔案對照見 `data/natural-voices-v4.js` 與 `assets/audio-natural/`；語音模型只用來產生隨附固定音檔，不因此變成網頁的即時任意文字語音模型。既有Qwen權重位置與CPU用途不變。
