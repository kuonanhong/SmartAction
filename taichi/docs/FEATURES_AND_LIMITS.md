# SmartAction v3 功能與實際範圍

本頁區分已寫入程式的功能與仍須實機驗證／資料建置的範圍。使用步驟見 [HTML 手冊](guide.html)，測試證據見 [測試報告](TEST_REPORT.md)。

| 項目 | 本版實作 | 明確限制 |
|---|---|---|
| 核心入口 | classic `js/game.js`，完整解壓後可從 `index.html` 操作 | CPU、相機、GPS、媒體和快取完整功能需 HTTPS／localhost |
| 課程 | 鄭曼青 37 主式；總計 13 類、131 節 | 每節一個程序目標姿勢；24 銜接資料未全動畫化；非拳師動捕或認證教材 |
| 跟隨老師 | 示範後等待玩家，各部位與總分達標且保持才通過 | 計分是遊戲角色端點距離，不是真人拳術判定 |
| 雙人對練 | 6 次電腦示範／玩家接招；24／18／14 秒窗口；逾時重試 | 電腦配對，不是兩位真人網路連線；不是完整攻防教學 |
| 節奏對打 | 最長 60 秒，出手／格擋提示、冷卻、體力和勝負 | 非接觸遊戲，不教真人實戰安全 |
| 三種等級 | 78／88／94 總分；部位至少 65／78／88；保持 1／1.6／2.2 秒；位置尺度 0.29／0.21／0.15 m | 尺度是高斯距離分數參數，不是允許誤差半徑；大師隱藏目標並禁輔助 |
| 手機語音 | 點按啟用與試聽、裝置聲音選擇、播放狀態、失敗提示、回覆重播；570 段 15 語鄭曼青招名／試聽本地 MP3 備援 | 系統語音優先；預錄為 eSpeak 機械合成，非真人或母語校聽；任意回答與其他拳種仍需相符系統語音；受播放手勢限制、無實機驗證 |
| 15 語 | 介面與課程字串，自動瀏覽器偏好與手動覆寫，阿拉伯文方向支援 | 地理位置不決定母語；專名可用轉寫；尚未母語教練審校；生成回答品質不保證 |
| 158 地點 | 搜尋、地區篩選、照片篩選、GPS／目錄／可用 OSM 附近結果 | 並非附近全部公園／道館目錄；資料與定位會不完整 |
| 本地實景素材 | 155 張授權照片，其中 5 真 360°；2 段各 12 秒平面影片 | 其餘照片非 360°；影片非環景影片、非直播；3 指定公園缺圖並明示 |
| 附近走走 | 儲存／恢復本頁進度、方向盤重設、跳／蹲、招呼、3 視角、水平視野約 +5% | 不是整份長期存檔；重整會失去中場快照；人物與居民是程序 3D |
| 移動與實景 | 3D 地面／物件視差，照片背景；±60 m 虛擬範圍、角色座標換算 | 不是公園精準 3D 重建、連續街景或真實 GPS 軌跡；平面照片無背面視差 |
| Google 地圖／街景 | 依角色虛擬座標開啟外部 Google 頁面 | 不下載重製街景；Google 決定影像是否存在；不是現場路線導航 |
| 居民回應 | 靠近後顯示／朗讀預寫問候 | 不是在地真人、不是生成式人物對話 |
| Qwen3 CPU | 本地 Wllama／WASM 文字生成、模型進度和驗證；15 分片約 484.22 MB 另附 | 非人臉／動作模型；小模型會答錯；手機記憶體與 CPU 速度未實測 |
| 人體辨識 | MediaPipe Lite 真實權重、CPU Worker、33 點、粗略正面 2D 比對 | 非深度、腰轉、受力或關節安全評分；不自動控制角色過關 |
| 離線 | 核心服務工作程序、使用者主動下載場景／預錄音、模型獨立儲存 | 首次須先下載；瀏覽器會清理儲存；地圖／即時附近／部分系統語音需網路 |
| 雙站發布 | 一個 bash 比對並分批傳網站、素材、模型；首頁增加入口、遊戲可返回 | 需 Git／Python／PAT；不替帳號授權；Pages 另設定；此次未代帳號推送 |
| 驗證 | 程式邏輯、資料覆蓋、授權資料與上傳情境可重現檢查 | 未做實體手機與真實瀏覽器 UI／WebGL／聲音／相機全流程測試 |
