# v2 功能與限制

| 項目 | 已實作 | 限制 |
|---|---|---|
| 本機入口 | classic game.js，index.html 可直接開核心遊戲 | CPU 模型、相機、定位請用 localhost/HTTPS |
| 預設拳譜 | 時中學社37式編號；13課131節 | 程序端點示意；24銜接資料尚未完整動畫化，非拳師認證 |
| 控制 | 多指手腳控制、換肢、轉腰、蹲伸、三視角、三難度、三模式 | 未完成真實手機畫面／觸控效能驗證 |
| 生成對話 | Qwen3 0.6B CPU，已實下載與原生CPU生成 | 484 MB 權重另附；小模型會答錯，手機WASM未實測 |
| 人體辨識 | Lite權重與CPU Worker內附；真人手腳粗略2D比對 | 非深度、腰轉、安全或太極專業分數；相機端到端未實測 |
| 語音 | 招式及回答朗讀、支援時語音輸入 | 系統語音需安裝；SpeechRecognition可能連網 |
| 多語 | 九種介面、狀態、課程與地點語言 | 模型生成語言品質不保證；專有拳名譯法需教練審閱 |
| 地點 | 9授權實景照、Google Maps、主動定位附近 | 需網路查詢；無授权照片時使用虛擬場景 |
| 發布 | 單一sh比較上傳、兩片一批、可重跑續傳 | 需Git/Python/PAT，Pages仍需帳號端設定；尚未替使用者push |
| 相容性 | API檢查與明確降級，完整附件 | 沒有『所有手機瀏覽器實機全通過』證據 |
