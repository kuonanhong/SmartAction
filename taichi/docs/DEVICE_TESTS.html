手機實機測試紀錄

請在您實際持有的手機或平板，用指定瀏覽器開啟遊戲，再逐項記錄結果。此表格不會自動執行測試，也不會傳送資料。

目前尚未宣稱通過任何手機實機測試。

本次交付的自動化檢查在 Linux / Node.js 執行。DOM 測試使用 JavaScript 模擬文件與 Canvas 替身，不等同 Safari、Chrome 實機、WebGL 畫面或手機 CPU 效能測試。下面的能力資訊也不等於功能通過。

另開遊戲 ↗查看已執行的自動化檢查

1. 測試環境

建議至少涵蓋：iPhone Safari、iPad Safari、Android Chrome、Android Firefox、Android Edge、Samsung Internet。若聲稱其他瀏覽器相容，也請各填一份；不能以一個瀏覽器的結果代替另一個。

2. 逐項操作

未操作維持「未測」。只有實際完成期待行為才選「通過」。選不適用時，請寫原因。

3. 能力快照與匯出

能力快照只檢查 API 是否存在，不請求相機、麥克風、定位、不下載模型。JSON 包含此頁網址、瀏覽器 User Agent、畫面尺寸及您填寫的內容；匯出前請自行確認。
