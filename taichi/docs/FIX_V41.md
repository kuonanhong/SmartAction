# v4.1 修正：電腦聲音與手機動作輔助

日期：2026-10-11。檔名與解壓資料夾仍保留 SmartAction_Taichi_Game_v4，頁面底部與診斷版號為 **4.1.0**。

## 使用方法

1. 完整解壓新 ZIP，保留所有子資料夾。這個更新包含既有照片、聲音與程式；Qwen 大型權重仍由選用下載器安裝。
2. 在練習畫面下方點「啟用／試聽語音」，或點音訊播放條的 ▶。第一次点「啟用聲音」會啟用，只有真正開始過播放後才能切換關閉。
3. 下方金色「動作輔助」可直接點選，無須橫向滑動工具列。基本級、專業級可用；大師級保留自行操作規則，會在按鈕旁顯示說明。走走模式中停用，回練習後恢復。
4. 若直接播放器的時間持續前進但聽不見，請檢查瀏覽器分頁／網站的靜音設定、系統輸出裝置及音量；程式不能替瀏覽器解除網站靜音。也可點「另開本式音檔」單獨播放。

## 一行更新兩站，不重新上傳模型

在解壓後、看得到 index.html 的資料夾開終端機：

```bash
bash Upload_Both_Sites.sh --web-only --fresh-login
```

它會更新 SmartAction/taichi 與獨立 taichi，保留遠端既有權重。需要 Token 時，授權兩個儲存庫的 Contents：Read and write。等待兩站最後一次 Pages 工作成功，再重新載入；頁尾應顯示 **v4.1.0**。

網址：
- https://kuonanhong.github.io/SmartAction/taichi/
- https://kuonanhong.github.io/taichi/

若仍顯示 v4.0，請等 Pages 發布完成後再重新載入。新版的核心 JS／CSS 有版本查詢參數，離線快取也已換代，避免舊版本資源混用。

## 修正原因與範圍

- 已唯讀核實：兩個線上網站都已是 v4.0.0，抽驗兩站共 6 個語音檔 HTTP 200；中文、英文樣本均可解碼且非靜音。因此沒有把桌機問題直接歸因於遺漏音檔。
- 舊版聲音預設顯示「開」，但播放器仍等待使用者啟用；第一次點按切換鍵反而關閉。新版按真實播放狀態顯示，並提供常駐試聽與原生音訊控制列，播放錯誤也顯示在控制區。
- 音檔失敗時加入有限備援：自然音檔 → 可用裝置語音 → 獨立機械音檔。最多 3 次，不循環。自由教練答案未預錄，仍使用可用系統語音。
- 手機的輔助原本是可橫捲工具列第 3 個按鈕，容易被右側按鈕擠出可視區。已移到不捲動的底部固定操作列，保持 44 px 按鈕。
- 輔助只在玩家回應階段消耗時限；30／60／120 fps 對齊效果一致，完成當招停止，不會連續自動通關。
- 大師級、走走及對打規則維持原定義；輔助對象為遊戲角色，不是對真人動作進行矯正。

程式測試、假音訊事件與 CSS 結構檢查已完成；沒有實體 Mac、Windows、iPhone 或 Android 發聲／排版實測，也尚未推送使用者儲存庫。
