一、先在本機開啟

  1. 完整解壓 SmartAction_Taichi_Game_v4.zip；保留 index.html、js/、data/、assets/、vendor/、models/、tools/ 等原有相對位置。
  2. 只要玩核心遊戲，可直接雙擊 index.html。CPU 模型、相機、定位、離線快取及影片等完整功能，請使用下面的本地伺服器或已部署的 HTTPS 網站。
  3. 電腦先安裝 Python 3。啟動檔僅用標準函式庫，不需 pip install；開啟後預設網址是 http://localhost:8088/。

二、手機與電腦如何選擇語音

  1. 使用 HTTPS 網站或本地啟動器，確認媒體音量與音訊輸出。第一次親手點「開始練習」或「啟用／試聽語音」；這些使用者手勢會同步嘗試解鎖播放，單純預設「朗讀：開」不代表已播放。
  2. 展開語音設定，選擇來源與聲音。自動模式對已收錄的中文／英文固定句優先使用自然合成音檔；其他內容選擇適合的系統聲音，已有固定錄音時也可使用機械備援。
  3. 男／女聲篩選適用於具有明確聲型資料的隨附音檔。瀏覽器系統語音 API 沒有可靠的性別欄位，系統聲音標為未提供／未知，不從姓名猜測性別。
  4. 調整語速後，同一瀏覽器會記住偏好。可重播當前語句；點「音檔試聽」可直接測試已收錄音檔，協助區分系統 TTS 與音檔播放路徑。
  5. 固定招名如遇系統 TTS 長時間沒有開始、失敗或卡住，會嘗試本地備援並顯示實際來源。舊朗讀的過期回呼不應改寫新朗讀狀態；重複操作會取消前一個有效工作，避免同時播兩句。
  6. Qwen 回答屬任意新文字，仍使用裝置的系統語音。即使選了自然音色，沒有對應預錄文字時也不能由固定 MP3 生成新句子；無相符系統聲音則保留文字並提示。回答生成後若沒聲音，請再親手點「朗讀回答」。

自然語音來源為開源 Kokoro-82M，權重只用於製作隨附 MP3；網站不搭載約 340 MB 的該語音模型，也不需下載它才能播放音檔。普通話聲型代碼為 zm_yunxi、zm_yunjian、zf_xiaobei、zf_xiaoyi；英文為 am_michael、am_puck、af_heart、af_bella。可選名稱、語言與檔案對照以 data/natural-voices-v4.js 為準，音檔在 assets/audio-natural/；18 語備援保留於 assets/audio/。

如果畫面顯示 blocked／拒絕播放，請先親手點試聽、確認音量和輸出，再用音檔試聽比較；僅靠截圖不能斷定是 iOS、Android、Chrome、靜音鍵或特定系統設定造成。即使收到瀏覽器播放事件，網頁也無法確認使用者是否真的聽見。切換背景會停止朗讀，回到前景再點試聽。部分系統聲音與語音輸入服務需要網路；這與本地 Qwen 文字推論是不同功能。

三、18 種語言與發音如何選擇

首次開啟依瀏覽器 navigator.languages 偏好順序選擇支援語言：繁體中文、簡體中文、英文、日文、韓文、西班牙文、法文、德文、葡萄牙文、義大利文、印尼文、越南文、泰文、阿拉伯文、印地文、俄文、土耳其文、荷蘭文。可手動指定，或恢復「自動（依瀏覽器）」；同一瀏覽器保留手動偏好。

GPS 決定附近搜尋位置，瀏覽器語言決定介面與預期發音；不能由所在地推定母語。Google 地圖連結盡可能帶入所選語言。18 語介面與全部課程名稱、說明、來源、練習要領及一般運動目標已列入資料覆蓋範圍；俄文、土耳其文、荷蘭文也包含全部課程，不只選單。

部分語言的要領是依同一 3D 目標姿勢產生的在地化提示，並保留安全限制，不是繁中／英文全文逐句翻譯。人名、地名可能保留原名或轉寫。字串完整不代表每句已經母語教練校閱，生成式回答品質也不保證。自然合成音檔只涵蓋普通話與英文固定句；18 語固定備援與任意文字系統 TTS 的能力需分開看待。

六、控制方法與三個視角

v4 將練習場景與底部控制盤放在相鄰的主要操作區，保留裝置安全區，隨可視視窗、直橫向、視窗縮放調整；設定項目可展開／收合，避免長設定區把場景與按鍵分隔。主要觸控目標按至少 44 px 設計；小螢幕仍可捲動設定。實際 Safari／Android 視窗工具列與鍵盤互動仍需裝置驗證。

手機／平板可以同時按兩個控制鍵。練拳模式下：左控制盤調整所選腳，右控制盤調整所選手；按各盤的切換鍵換腳／換手；另有抬腳、前伸、轉腰、蹲下與伸展。第一視角從角色眼睛觀看；第二視角靠近角色；第三視角看完整角色與老師。

七、附近走走：移動、地圖與恢復練習

  1. 練到一半按「附近走走」。目前招式、角色姿勢、分數、回合與暫停狀態留在本頁記憶體；不用重新開始。
  2. 左盤改成移動整個角色，右盤改成環視與抬頭，不再要求切換左右手腳。可跳躍、按住蹲下、走近虛擬居民打招呼。
  3. 居民會顯示與朗讀預先編寫的在地招呼，不是即時真人，也不是 Qwen 生成回答。
  4. 三視角都能使用。走路模式將水平視野約增加 5%，屬廣角視野調整，不是精密魚眼鏡頭校正。
  5. 地面、樹木、椅子與程序 3D 人物隨相機位移呈現透視與視差。真實照片作為實景背景；五個真正 360° 場景可環視，平面照片不會被冒稱為完整 360°。
  6. 虛擬步行限定在場景中心東西、南北各約 ±60 m 的範圍；畫面把角色位移換算成附近經緯度，並標示「虛擬座標」。這不是手機實際 GPS 路線，也不是可用於實地導航的測量結果。
  7. 點 Google 地圖或 Google 街景連結，會在外部 Google 頁面查看該座標；有沒有街景及該座標的影像由 Google 提供。本遊戲沒有下載、內嵌或重製 Google 街景影像。
  8. 按「繼續練習」，恢復進入散步前的角色姿勢、進度與視角。若離開頁面或重新整理，這份中場快照不會作為完整存檔永久保留；重新整理前先完成當前回合。

目前場景是「真實照片＋程序 3D 公園」；不是每個公園的逐棵樹、道路、建築、坡度數位孿生，也不是連續街景漫遊。照片不會因角色前進而產生未拍到的背面細節，切換位置也不是實際跨街導航。

八、實景、附近公園與授權

目錄含 158 個不同地點、155 張本地實景照片，其中 5 張是真正 360° 全景；另附 2 段各 12 秒的普通平面實景影片。影片不宣稱是 360° 影片或即時直播。可搜尋公園或城市，依台灣北、中、南、東／離島、世界篩選，以及只顯示有照片的地點。

高雄包含您指定的大東、澄清湖、果嶺、鳥松濕地、觀音湖、金獅湖、中山大學、壽山、觀音山、美濃中正湖等。夢裡森林公園、雙湖公園、仁武公園尚缺可驗證授權照片，顯示無照片狀態；夢裡另缺可靠座標，提供地名地圖搜尋，不允許冒用他處照片或座標啟動散步。衛武營預設照片是公園自然探索區，不宣稱為榕園同一鏡位。

按「尋找附近」才請求定位權限。瀏覽器可能拒絕、精度不足，或定位到網路出口。附近結果取自隨附目錄與可用的 OpenStreetMap 查詢；無法保證列出濱山街附近「全部」中大型公園或道館。道館另有 Google 搜尋入口，可補查營業與交通資訊。天氣、季節、氣候和時段是視覺效果，不是即時天氣預報。

也附 Download_Model.command／Download_Model.bat。之後從 localhost／HTTPS 開啟遊戲，展開「與練拳教練對話」→「離線生成式模型」→「載入已下載模型」。也可在網頁選「下載並啟用」，或匯入相容的 .gguf。看到 Qwen3／CPU 就緒才是生成式回答；未載入時是明確標示的課程資料提示。

瀏覽器下載的權重存在瀏覽器儲存空間，不會自動變成本機專案資料夾檔案，也不會自動上傳 GitHub。模型未下載、載入失敗或記憶體不足，不會阻止核心練拳按鈕。Qwen 是小型通用文字模型，仍可能答錯，不能替代老師或醫療專業判斷。

真人相機比對

在 HTTPS／localhost 點「真人肢體比對」→「啟用攝影機」。站在可拍到全身、手腕與腳踝的位置。影像在本機 CPU Worker 處理，不錄影、不上傳；生成式教練只接收有效的數字摘要，不收到影像。停止或頁面進入背景會關閉相機。

真人分數與遊戲角色分數分開；相機不會操控角色自動過關。沒有完整身體、低可信度、側身或需要顯著腰轉時不應解讀為可靠評分。詳見 docs/BODY_TRACKING.md。

十、有網路與離線怎麼用

情況操作／可用功能
第一次線上使用從 HTTPS 開啟，等待核心載入，按「下載離線場景」保存照片與影片；Qwen 需另下載並載入
之後同一瀏覽器離線已快取的核心、場景和模型可使用；前提是快取未遭清除且瀏覽器功能允許
電腦完整本機套件用本地啟動檔；本地已有的素材不需連網讀取，模型也須先取得完整分片
Google Maps、街景、附近即時查詢需要網路；離線不保證可用
朗讀已下載的自然／機械鄭曼青招名與試聽 MP3 可離線；任意文字仍需本機可用系統語音，部分系統聲音需要網路
語音輸入視瀏覽器服務而定，不宣稱離線語音辨識

「下載離線場景」若顯示部分失敗，可再按一次補齊。首次不要假設所有場景都已自動預載。私人瀏覽、空間不足或系統清理會影響儲存；完整本地套件是另一路徑，不依賴瀏覽器曾看過哪張照片。

十一、一個指令上傳兩個網站

請使用完整 v4 資料夾。Upload_Both_Sites.sh、Upload_SmartAction.sh 與 index.html 在同一層，tools/ 要完整保留。Mac／Linux 需要 Bash、Git、Python 3.8 以上；Windows 請安裝 Git for Windows 與 Python 3，從 Git Bash 執行。

第一次的 GitHub 準備

  1. 登入 kuonanhong，確認已有公開 SmartAction 和 taichi 儲存庫。需要時從 https://github.com/new 建立；真正的空儲存庫由腳本初始化，不必先放 README。
  2. 開啟 https://github.com/settings/personal-access-tokens/new 建立 Fine-grained personal access token。
  3. 設定名稱與適當期限；Resource owner 選 kuonanhong；Only select repositories 同時勾選 SmartAction、taichi。
  4. Repository permissions 的 Contents 設為 Read and write；Metadata 保留基本讀取權限。這個上傳流程不需要把 Token 放進網頁或程式碼。
  5. 產生後自行保存 Token。Git 問 Password 時貼 Token，不能用 GitHub 帳號密碼；終端機不顯示輸入字元是正常現象。請勿把 Token 貼到聊天或上傳檔案。
  6. Token 管理／修改入口：https://github.com/settings/personal-access-tokens 。若 expired、repository 未選或缺少 Contents 寫入，先修正權限。

在完整 v4 資料夾內只需：

bash Upload_Both_Sites.sh --fresh-login

若完整套件解壓在 Mac「下載項目」，可從任意工作目錄直接貼：

bash "$HOME/Downloads/SmartAction_Taichi_Game_v4/Upload_Both_Sites.sh" --fresh-login

.sh 必須留在遊戲 index.html 同一層；不要只把腳本放在 Downloads 根目錄就執行。

這個雙站指令預設包含模型：先找現有／旁邊權重包的分片，驗證後只補齊缺少部分；再比較本地與遠端內容，分批上傳網站、照片、自然／備援音檔、版面程式與模型。--fresh-login 只繞過本次的舊憑證；不替 Token 增加權限，也不修改其他專案的全域登入設定。

只更新網站、照片與程式，不補下載／上傳 Qwen 分片：

bash Upload_Both_Sites.sh --web-only --fresh-login

--web-only 保留遠端已存在的權重，不會把它們刪掉。單站也可用：

bash Upload_SmartAction.sh --site smartaction --with-model --fresh-login
bash Upload_SmartAction.sh --site taichi --with-model --fresh-login
儲存庫放置遊戲內容發布後網址
kuonanhong/SmartActiontaichi/ 子目錄；根首頁新增太極入口https://kuonanhong.github.io/SmartAction/taichi/
kuonanhong/taichi根目錄直接放 index.html 及同層資料夾https://kuonanhong.github.io/taichi/

腳本傳的是 v4 資料夾內部檔案，不是再嵌入 SmartAction_Taichi_Game_v4/ 外層。兩個網址使用相同相對路徑，index.html 不需改模型位置。SmartAction 首頁的新增圖示連向可玩的 Pages 網址 ./taichi/；遊戲中可返回協會主頁。GitHub 儲存庫目錄是看原始碼，不是玩家的遊戲入口。

網站每批最多 96 MiB，15 個 Qwen 分片按每兩片／64 MiB 分成 8 批；約 110～150 MB 網站通常兩批，每站首次最多 10 次 push，相同批次跳過。先前同一小時的 Pages 建置仍可能占用每站 10 次 build 軟性限額，需檢查最後一次部署。

上傳不刪除遠端其他內容、不 force push。中途斷線會核對遠端提交，已成功的批次可跳過；重跑同一指令比對續傳。如果停在第二站，第一站成功的內容仍保留。遇到 403 請先確認兩個儲存庫的 Token 權限；遇到持續網路斷線，可改穩定網路後重跑。

上傳完成後，兩站分別開啟 Pages

  1. 開啟 https://github.com/kuonanhong/SmartAction/settings/pages 和 https://github.com/kuonanhong/taichi/settings/pages 。
  2. 若尚未設定，選 Deploy from a branch → 腳本顯示的分支（通常 main）→ /(root) → Save。
  3. 已有自訂 Actions 發布流程時，保留原發布方式並確認它會包含 taichi/；腳本不會自動改帳號端 Pages 設定。
  4. 到兩站 Actions 確認最新部署成功，再打開上表的 Pages 網址。
  5. 如果仍看到舊內容，重新整理／關閉後再開，必要時清除此網站的舊快取後重載；清除快取也會移除離線場景或模型，需重新下載。

Everything up-to-date 或 create mode 單獨出現不代表兩站完成；請看腳本最後的兩站核對完成訊息，再看各站 Pages Actions。詳見 docs/UPLOAD_PAT.html。本次交付提供腳本與測試，沒有代您登入或實際推送 GitHub。

十二、教材、相容性與驗證範圍

鄭曼青 37 式的名稱與編號依時中學社《學員手冊》；每式是一個遊戲目標姿勢，另外 24 個重複／銜接／收式保留為資料，尚未全部逐段動畫化。其餘武術是原有的入門示意節點，不是新增完整流派教材。人物、居民與公園物件為程序 3D，非真人寫實或拳師動作捕捉。

已針對程式邏輯、資料覆蓋與上傳流程執行可重現測試；詳細測試數字以 docs/TEST_REPORT.md 為準。沒有完成 iPhone、iPad、Android 實機或各瀏覽器真實 WebGL／語音／相機畫面驗證，不宣稱各款手機全通過。缺少必要 API 時會提示限制，核心練拳功能與模型保持分開。可用 docs/DEVICE_TESTS.html 記錄您自己的裝置測試。
